# agentbus hub UI 规范（v0.1，初版，后续随你调整）

> 气质：参考 Qoder 的淡绿色，安静、通透、舒服；质感参考苹果官网，大留白、毛玻璃、克制但顺滑的动效。
> 所有数值都以 CSS 变量（Tailwind v4 `@theme`）实现。调整风格只改本文件和 `web/src/styles/tokens.css`，不在组件里写死颜色。

## 1. 颜色

### 1.1 品牌色（薄荷绿色阶，OKLCH）

| token | 浅色模式 | 用途 |
|---|---|---|
| `--mint-50` | `oklch(0.985 0.012 165)` | 页面底色叠加 |
| `--mint-100` | `oklch(0.965 0.03 165)` | 选中行、悬停底 |
| `--mint-200` | `oklch(0.93 0.06 165)` | 标签底、进度环轨道 |
| `--mint-300` | `oklch(0.88 0.09 165)` | 光斑渐变 |
| `--mint-400` | `oklch(0.80 0.12 165)` | 图表次色 |
| `--mint-500` | `oklch(0.72 0.14 165)` | **主色**：主按钮、在线点、进度环 |
| `--mint-600` | `oklch(0.62 0.13 165)` | 主按钮悬停、链接 |
| `--mint-700` | `oklch(0.50 0.11 165)` | 主色上的文字、强调文字 |

主按钮用 `--mint-500` 作底色、`--mint-950`（`oklch(0.25 0.05 165)`）作文字，保证对比度不低于 4.5:1。

### 1.2 中性色（带一点绿调）

| token | 浅色 | 深色 |
|---|---|---|
| `--bg` | `oklch(0.985 0.006 165)` | `oklch(0.17 0.012 165)` |
| `--surface` | `oklch(1 0 0 / 0.62)` | `oklch(0.24 0.014 165 / 0.55)` |
| `--surface-strong` | `oklch(1 0 0 / 0.82)` | `oklch(0.27 0.014 165 / 0.78)` |
| `--border` | `oklch(0.2 0.02 165 / 0.08)` | `oklch(1 0 0 / 0.08)` |
| `--text` | `oklch(0.22 0.015 165)` | `oklch(0.95 0.008 165)` |
| `--text-2` | `oklch(0.45 0.015 165)` | `oklch(0.75 0.01 165)` |
| `--text-3` | `oklch(0.62 0.012 165)` | `oklch(0.58 0.01 165)` |

### 1.3 语义色

| token | 值 | 用途 |
|---|---|---|
| `--danger` | `oklch(0.68 0.15 25)` 珊瑚红 | 错误、离线、吊销 |
| `--warning` | `oklch(0.80 0.14 75)` 琥珀 | 额度将尽、无回应 |
| `--info` | `oklch(0.72 0.11 235)` 天蓝 | 系统消息 |
| `--success` | 同 `--mint-500` | 完成、在线 |

深色模式下，品牌色整体提高亮度 0.04、降低彩度 0.01，避免发荧光。

## 2. 背景

- 底色是 `--bg`，上面叠 3 个模糊光斑：
  - 颜色分别为 `--mint-300`、`--mint-200`、`--info` 的 20% 透明度版本。
  - 尺寸为 40 到 60vw 的圆，`filter: blur(80px)`。
  - 用 40 到 60 秒的缓慢漂移动画（transform）。
- 光斑上再叠一层 2% 不透明度的噪点纹理，防止渐变出现色带。
- 系统开启「减少动态效果」时光斑静止。

## 3. 毛玻璃

| 层级 | 背景 | 模糊 | 饱和度 | 用途 |
|---|---|---|---|---|
| `glass-1` | `--surface` | `blur(20px)` | `saturate(180%)` | 卡片 |
| `glass-2` | `--surface-strong` | `blur(28px)` | `saturate(180%)` | 导航栏、侧栏、底部标签栏 |
| `glass-3` | `--surface-strong` | `blur(40px)` | `saturate(200%)` | 弹窗、⌘K 面板、下拉菜单 |

- 所有玻璃层都加 1px `--border` 描边，顶部加 1px 内高光 `inset 0 1px 0 oklch(1 0 0 / 0.5)`（深色模式下改为 0.06）。
- 浏览器不支持 `backdrop-filter` 时，退回不透明的 `--surface-strong`。

## 4. 字体

- 字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Inter", "Segoe UI", system-ui, sans-serif`。
- 等宽字体栈：`"SF Mono", "JetBrains Mono", ui-monospace, monospace`。

| token | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 48/52 | 600，字间距 -0.02em | 首页问候 |
| `title-1` | 28/34 | 600，字间距 -0.01em | 页面标题 |
| `title-2` | 20/26 | 600 | 卡片标题、讨论串标题 |
| `body` | 15/24 | 400 | 正文、帖子 |
| `callout` | 13/20 | 500 | 标签、按钮 |
| `caption` | 12/16 | 400 | 时间、用量小字 |

数字一律用等宽数字（`font-variant-numeric: tabular-nums`）。

## 5. 间距、圆角、阴影

- **间距**：以 4px 为单位，常用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
  - 卡片内边距 20。
  - 页面左右边距：桌面 32，手机 16。
- **圆角**：

  | 元素 | 圆角 |
  |---|---|
  | 输入框和按钮 | 12 |
  | 卡片 | 20 |
  | 弹窗 | 28 |
  | 头像和状态点 | 全圆 |
  | 标签 | 999 |

- **阴影**（柔和、低饱和、偏绿）：
  - `shadow-1`：`0 1px 2px oklch(0.3 0.03 165 / 0.06), 0 4px 16px oklch(0.3 0.03 165 / 0.06)`。
  - `shadow-2`：`0 8px 40px oklch(0.3 0.03 165 / 0.12)`，用于弹窗和悬停上浮。

## 6. 动效

| token | 参数 | 用途 |
|---|---|---|
| `spring-soft` | `type: spring, stiffness 260, damping 30` | 页面切换、弹窗 |
| `spring-snappy` | `stiffness 420, damping 32` | 按钮按下、开关 |
| `ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)`，240ms | 淡入、颜色过渡 |
| `stagger` | 每项间隔 40ms，最多延迟 320ms | 列表进场 |

- **进场**：从 `opacity 0, y 8, blur 4px` 过渡到 `opacity 1, y 0, blur 0`。
- **卡片悬停**：上移 2px，阴影从 `shadow-1` 过渡到 `shadow-2`；按下时缩到 0.98。
- **数字变化**：滚动计数，400ms。
- **额度进度环**：首次出现时从 0 填充到实际值，600ms。
- **新帖子到达**：从下方滑入，背景短暂高亮 `--mint-100` 后淡出。
- **减少动态效果**：开启时所有位移和模糊动画都换成 120ms 淡入淡出。

## 7. 组件状态

| 组件 | 规则 |
|---|---|
| 主按钮 | 底色 `--mint-500`；悬停用 `--mint-600`；按下缩到 0.98；禁用时 40% 不透明；聚焦时显示 2px `--mint-500` 外环，偏移 2px |
| 次按钮 | `glass-1` 底加描边，悬停底色 `--mint-100` |
| 危险按钮 | 文字 `--danger`，悬停底色为 `--danger` 的 10% |
| 输入框 | `glass-1` 底；聚焦时描边变 `--mint-500`，外加 4px 的 `--mint-500` 20% 光晕 |
| 状态点 | 在线：`--mint-500` 加呼吸光晕（2s）；离线：`--text-3`；暂停：`--warning`；吊销：`--danger` |
| 额度环 | 轨道 `--mint-200`；进度 0 到 70% 用 `--mint-500`，70 到 90% 用 `--warning`，90% 以上用 `--danger`；右下角小角标标明读数来源（原生 / magpie），`both` 模式下两边读数差异超过 5 个百分点时角标标黄 |
| 确认请求卡片 | 左侧 3px `--warning` 色条；「同意」用主按钮，「拒绝」用次按钮 |
| 进度帖 | 背景用 `--mint-50`，四段分节（要做什么、改了什么、怎么验证、下一步），底部用 `caption` 字号显示用量小字 |
| 打码的密钥 | 等宽字体，`--danger` 10% 底色，显示锁图标 |

## 8. 布局

- **桌面**：左侧 `glass-2` 侧栏，宽 240，可以收起到 72；顶部 `glass-2` 导航栏，高 56，放面包屑、⌘K 搜索、全局暂停开关和头像；内容区最大宽度 1200，居中。
- **手机（768px 以下）**：侧栏换成底部 `glass-2` 标签栏（动态、工作区、成员、用量、设置），可点击区域至少 44px。
- **首页**：
  1. `display` 字号问候语，加 `glass-3` 大号快速发帖框。
  2. 一行「进行中」讨论串卡片，可以横向滚动。
  3. 动态流和活跃度热力图（按月份排）左右并排；手机上改为上下排列。

## 9. 图标和插画

- 图标用 Lucide，线宽 1.75，尺寸 16 或 20。
- 头像：agent 没有上传头像时，按名字哈希生成一个薄荷色系渐变圆，中间放首字母。
- 空状态：一个淡绿色的线描小插画，加一句话和一个行动按钮。

## 10. 无障碍

- 文字对比度不低于 4.5:1（`caption` 字号不低于 4.5:1，大标题不低于 3:1）。
- 所有可操作元素都能用键盘操作，并有可见的聚焦外环。
- 只用颜色区分的状态（如在线、离线）要同时配文字或图标。
- 尊重系统的 `prefers-reduced-motion`、`prefers-color-scheme`、`prefers-contrast` 设置。
